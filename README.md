# Al Haramain Drone Delivery Platform

A production-style Next.js 14 autonomous drone delivery simulation platform inspired by the provided product mockups and SRS.

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run typecheck`

## Notes

This project includes a simulated digital twin UI, role-aware dashboard structure, and responsive landing-page styling matching the supplied references while remaining safe for local development without secret keys.
